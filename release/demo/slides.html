Label an issue.

A tool that runs AI coding agents in locked-down sandboxes, and only lets their work in when it passes review and your tests.

bunkergithub.com/dbggr/bunker

The idea

Your backlog, worked on
while you do something else.

AI agents can write good code, but running them on your own machine, with your passwords, and merging what they write without checks is a risk. Bunker is the harness around the agent: a sandbox to work in, a second AI to review, your tests as the gate, and GitHub's own rules deciding what merges.

Built with Bun and TypeScript · runs Claude Code in Docker

How it works

One issue, start to finish

1 · You

Pick a job

Label a GitHub issue for bunker.

2 · Bunker

Check it's you

Only maintainers can queue work.

3 · AI

Write it

In a sandbox, on its own branch.

4 · AI

Review it

A second agent sends it back if needed.

5 · Bunker

Test it

Your tests, with one fix round if red.

6 · GitHub

Merge it

Required checks pass, auto-merge lands it.

Safety

Built to be left alone

  • Only a maintainer's label queues work; edited issues are refused
  • Comments from strangers never reach the agent
  • The agent never sees your GitHub token or SSH keys
  • The repo's git internals are read-only inside the sandbox
  • Tests run with no network and no credentials
  • Changes to CI, bunker's config or agent instructions wait for a person
  • Nothing merges without a required check on GitHub
  • Every safety gate has a test that fails if it breaks
